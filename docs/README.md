# DeskCountChen —— Windows 桌面图标收纳工具

把桌面上散乱的快捷方式按"分类"收进文件夹，点一下入口图标就弹出半透明圆角面板，
面板里点一下就能启动程序。

## v1.5 变更（毛玻璃面板 + 点桌面必关 + 悬停/动画 + 全局设置）

### 一、面板关不掉 —— 已修复（P0）

**现象**：呼出面板后点桌面关不掉；呼出后 10 秒不动鼠标再点桌面 100% 关不掉；
必须先点一次面板内部再点桌面才能关。

**根因**：面板由 SAO 的 HUD 图标唤起后台进程，Windows 前台锁定让面板
**从未真正成为前台窗口**，点桌面时收不到任何"失焦"事件，旧的关闭逻辑
只依赖激活事件，所以永远不触发。

**修复**：面板打开期间启用轻量轮询（40ms）——鼠标左键在**面板外**按下即关闭；
同时 `show()` 时尽力抢一次前台、前台丢失 ≥180ms 也作为兜底关闭路径。
安全红线：面板刚打开的前 300ms 是宽限期；面板内部点击/拖拽/长按/拖出窗口
都不会误关。日志可查原因：

```
面板已关闭（原因=deactivate|click-outside|focus-lost|esc）: <cat_id>
```

复现/验收探针：`.venv\Scripts\python.exe tests\probe_close_bug.py`
（修复前在 v1.4 上跑 A 用例 FAIL，修复后 6/6 PASS）。

### 二、毛玻璃面板（P1）

- 面板背景默认改为**毛玻璃**：截取面板背后的桌面 → 1/8 降采样模糊 → 叠加
  分类自己的背景色/透明度 → 顶部 1px 高光 + 内侧暗边（玻璃厚度感）；
- 单次生成耗时实测约 8ms（中位数，`tests\probe_visual_v15.py`），打开面板无感；
- 截屏失败 / 全黑（锁屏、远程桌面）自动回退纯色，不会黑一块；
- 设置里新增「面板材质」：毛玻璃 / 纯色，按分类独立，旧配置缺该项默认毛玻璃；
- `透明度 = 0` 的行为不变：连模糊底一起不画，只剩图标和文字。

### 三、悬停与出现动画（P2）

- 图标悬停：放大到 1.08（以图标中心为基准）、名字颜色变亮，150ms 缓动；
- 面板出现：从 94% 缩放到 100%、背景由透明淡入（140ms，OutCubic），
  贴合图标弹出时"从图标方向展开"；关闭有 80ms 淡出；
- 全程未使用窗口透明度，透明度 0 时"只剩内容"的语义不变。

### 四、全局设置：应用到全部分类（P2）

分类设置对话框底部新增「应用到全部分类」：把当前的面板宽高 / 圆角 / 背景色 /
透明度 / 弹出位置 / 材质复制到**所有**分类（显示文字、图标图片、图标尺寸保持
各自独立），按钮会显示"已应用到 N 个分类"并**立即落盘**；正开着的面板会关闭，
重新打开即生效。

## v1.4 变更（入口交给 SAO Utils 2 + 数据根可配置）

### 一、入口不再是桌面图标，而是 SAO Utils 2 的 HUD 图标

```
SAO Utils 2 HUD 图标（单击）
   → %USERPROFILE%\DeskCountChen\.launchers\启动-<分类>.lnk
   → pythonw.exe main.py --open "<分类目录名>"
   → 第二实例唤醒第一实例 → 弹面板
```

- DeskCountChen **不再往桌面写 .lnk**（分类增删不再影响桌面整洁）；
- 启动器 .lnk 生成在私有目录 `.launchers`，供 SAO 的 "Change Action" 引用；
- HUD 图标是 SAO 的浮层，**Win+D 后依旧在**；
- 详细配置步骤见 **[`docs/SAO-接入.md`](SAO-接入.md)**；
- 托盘菜单新增「打开启动器目录（供 SAO 引用）」。
- 仍保留 `app.shortcut_mode = "desktop"`（v1.3 行为，写真实桌面）作为可回退模式；
  首次切到 launcher 模式时会**安全清理**桌面上的旧 .lnk——删除前用 Shell 解析
  确认 target 是 `python(w).exe` 且参数含 `--open`，其余一律保留。

### 二、数据根可配置（分类数据可以放在别的盘）

- `app.data_root`（空 = `%USERPROFILE%\DeskCountChen`），本机设为 `E:\快捷方式SAO`；
- **程序目录不漂移**：`.config.json` / `.icons` / `.ico` / `.logs` / `.launchers`
  永远在 `%USERPROFILE%\DeskCountChen`——数据盘拔掉也能启动、也有日志；
- `app.category_exclude`（默认 `["快捷方式", "桌面", "z全部"]`）：自动登记分类时
  跳过的目录名（大小写不敏感），避免把数据根里的杂项目录变成分类；
- 已登记但新数据根里不存在的分类 → 标"隐藏"（不删配置、不动皮肤）。

### 三、图标去掉"快捷方式"小箭头 / 面板名称去扩展名

- `app.strip_shortcut_overlay = true`：解析 .lnk 拿到真实目标（或它的自定义图标），
  对目标取图标 → 面板里显示的是程序本身的脸，不叠小箭头。解析失败自动回退到
  原逻辑（允许带箭头，绝不空图、绝不灰显）。
- `app.strip_extensions = true`：面板内 `微信.lnk` 显示为 `微信`、`QQ.exe` 显示为 `QQ`，
  文件夹保持原名；**真实文件名仍存在 `NAME_ROLE` 里**，排序 / `.order.json` /
  启动定位全不受影响，悬停可看完整文件名。

## v1.2 变更（真实桌面快捷方式 + 拖拽插入语义）

### 一、桌面图标不再是"悬浮窗"，改成真实 `.lnk`

v1.1 的做法是"每个分类自绘一个置底悬浮窗"，靠 Win32 `SetWindowPos` 贴在 Progman
之上。这条路有两个绕不过去的坑：**Win+D 会把悬浮窗一起藏起来**（只能靠 500ms 看门狗
去救，抖一下才回来），以及**悬浮窗永远和"桌面图标"的视觉/交互不完全一致**。

v1.2 **彻底放弃悬浮窗体系**（`app/windows/icon_window.py` 已删除，看门狗、
`sink_to_desktop`、`restore_noactivate`、`is_hidden_or_iconic` 全部移除），改成：

> **每个分类对应一个普通的 `.lnk` 快捷方式**，由 Windows 资源管理器自己
> 绘制、自己管理位置、自己参与框选 / 排序 / Win+D。

（v1.4 起这个 .lnk 的落点从"真实桌面"换成私有 `.launchers` 目录，其余设计不变。）

- 快捷方式指向 `.venv\Scripts\pythonw.exe`，参数为 `<项目根>\main.py --open "<分类目录名>"`，
  工作目录为项目根，图标为该分类皮肤的 `.ico`。
- **桌面路径不去猜**：用 `SHGetKnownFolderPath(FOLDERID_Desktop)` 取真实桌面目录，
  OneDrive / 企业重定向都能正确处理（不读注册表、不拼 `%USERPROFILE%\Desktop`）。
- **位置由 Windows 管**：配置里不再存 `x/y`；旧配置里的 `x/y` 会被静默忽略。
- **`cat.visible` 语义**：是否保留这个 `.lnk`（False = 删除，分类仍可从托盘进入）。
- **启动时幂等同步**：只补建缺失的、更新改名的 / 换了图标的、删掉已隐藏或已注销的。
  内容没变的 `.lnk` **不会重写**，判据存在 `.icons\lnk_state.json` 的内容指纹里。


### 二、单实例唤醒（点入口图标不弹框）

第二实例被拉起时（互斥量已存在），**不弹"已在运行"对话框**，而是：

1. 通过 `QLocalSocket` 连到第一实例的 `QLocalServer`（服务名 `DeskCountChen.single.v1`）；
2. 发一条 `{"action":"open","dir":"<分类目录名>","x":123,"y":456}`（UTF-8 + 换行）；
3. **静默退出**（退出码 0）。

第一实例收到后打开对应分类面板，并把面板**放在鼠标落点**（也就是用户点图标的位置）；
该分类若设了"屏幕居中"，仍然居中。只有连不上第一实例时（极端异常）才降级提示一次。

### 三、面板内拖拽：密集插入语义（v1.3，完全对齐手机桌面文件夹）

v1.1 是"拖 A 到 B 上 = A、B 互换"，v1.2 曾改成"插入 + 保留空位"——实测空位
随拖拽无界累积，面板越拖越散。**v1.3 按用户最终决策整体废除空位体系**：

- 拖 A 落到图标 B 上 → A **插入** B 的位置，B 及其后的图标整体顺移一格，
  A 原来的位置由后面的图标**自动补齐**——网格永远紧凑，不产生任何空格；
- 拖到面板空白处 / 网格外 → 追加到末尾；
- 落在自己身上（含紧邻的下一格）→ 顺序不变；
- 多选批量（含 Ctrl 不连续多选）：一次搬一整块，块内相对次序不变；
  落点按"插到落点图标之前"解释，往后拖没有行号偏移；
- 历史 `.order.json` 里的空位记录与幽灵名在加载时自动清除（自愈，无需迁移）。

实现上纯逻辑在 `app/slot_ops.py::apply_move()`（密集空间运算 + 落点行号修正），
`app/windows/panel_grid.py` 只负责调用它并重建模型。

## 首次使用

1. **安装依赖**（一次性）：
   ```
   desktopbox\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```
2. **启动**：双击 `run.bat`（无控制台窗口）。调试用 `run.bat --console`
   （带控制台真实运行，日志同时打进窗口）。基础设施自检：
   `.venv\Scripts\python.exe main.py --selfcheck`（打印"基础设施就绪"后退出，
   已有实例在跑时也能用）。
   已经在跑时再双击**不会**新起实例、也**不会**再弹"已在运行"框（见上）。
3. **首次启动**会自动创建数据目录（`app.data_root`，默认 `%USERPROFILE%\DeskCountChen`）
   下的默认分类 `常用\`，并在 `.launchers\` 生成 `启动-常用.lnk`；
   再到 SAO Utils 2 里让 HUD 图标指向它（见 [`docs/SAO-接入.md`](SAO-接入.md)）。

## 如何使用

- **打开面板**：**单击** SAO Utils 2 的 HUD 图标（它执行 `.launchers\启动-<分类>.lnk`）；
  或右键托盘图标 → 该分类 → 打开面板。
- **新建分类**：托盘图标右键 → 新建分类（会在数据根下创建同名文件夹，并立即
  生成对应的 `启动-<分类>.lnk`；要在 SAO 里新建一个 HUD 图标指向它）。
- **放入内容**：把快捷方式（.lnk）、程序（.exe）、文件夹（目录）拖进
  `<数据根>\<分类名>\`（本机是 `E://快捷方式SAO//<分类名>//`）。
  目录里有什么，面板就显示什么；其他类型文件不显示。
  **面板不向下进入子目录**——点文件夹会打开资源管理器。
- **面板内排序**：按住条目拖动 >4px 直接重排（插入语义，见 v1.2 变更第三条）；
  顺序保存在分类目录内隐藏的 `.order.json`。新增的条目按名称（与资源管理器一致的
  自然排序）排在末尾。
- **编辑态**：面板条目上静止按住 400ms 进入编辑态（图标抖动、可多选）；
  编辑态下拖动 = 批量移动选中的多个条目；Esc / 点空白 / 关面板退出。
- **调整面板**：拖面板边缘可拉伸（宽高记忆，最小 240×160）；
  右下角"打开此文件夹"打开数据目录。
- **分类设置**：托盘右键 → 该分类 → 设置…。可改：显示文字、图标图片、面板宽高、
  圆角（0–24）、背景色、透明度（0–100，0=只剩内容）、弹出位置（贴合鼠标落点 / 屏幕居中）。
  **全部按分类独立**。改图标图片后会重新生成 `.ico` 并重建快捷方式，桌面图标随之变化。
- **重命名**：托盘右键 → 该分类 → 重命名…（改显示文字 + 启动器文件名，不动数据目录；
  改完要同步更新 SAO 里那个 HUD 图标的指向）。
- **隐藏分类**：托盘右键 → 该分类 → 隐藏（删除启动器快捷方式）。`.lnk` 被删除，
  分类本身仍保留在托盘菜单里（标"（已隐藏）"），随时可以"显示（重建启动器快捷方式）"。

## 目录结构

程序目录（**永远在 `%USERPROFILE%\DeskCountChen`，不随数据根漂移**）：

```
%USERPROFILE%\DeskCountChen\
├── .config.json          全局配置（app.data_root / 每分类外观参数）
├── .icons\
│   ├── <cat_id>.<ext>    自定义分类图标（选入后自动复制一份）
│   ├── ico\<cat_id>.ico  由分类皮肤生成的快捷方式图标（自动缓存/重建）
│   └── lnk_state.json    快捷方式同步指纹 + 落点（where）
├── .launchers\            ★ 启动器 .lnk（供 SAO 引用）
│   ├── 启动-游戏加速.lnk
│   └── 启动-影音娱乐.lnk ...
├── .logs\app.log         日志（512KB×2 轮转）
├── .logs\crash.log       致命崩溃栈（faulthandler，正常时不产生）
└── .config.json.bak-*    迁移脚本生成的配置备份
```

数据根目录（`app.data_root`，本机 `E://快捷方式SAO`）：

```
E://快捷方式SAO//
├── 游戏加速\  影音娱乐\  工作学习\  社交通讯\  系统硬件\  文档下载\
│   └── .order.json       隐藏的顺序文件（拖拽排序时写回）
├── 快捷方式\  桌面\  z全部\   ← app.category_exclude 跳过，不登记为分类
```

桌面上**不再有任何由 DeskCountChen 写出的文件**。

## 人工验收清单（对应 18 条需求）

| # | 需求 | 验收步骤 | 预期 |
|---|------|---------|------|
| 1 | 分类+可编辑文字 | 托盘→该分类→重命名 | 启动器 .lnk 文件名与面板标题变化，数据目录名不变（SAO 指向需同步改） |
| 2 | 图标尺寸可调 | （v1.2 起由 Windows 决定桌面图标尺寸） | 面板内条目尺寸仍按皮肤生效；桌面图标大小随系统"图标大小"设置 |
| 3 | 图标位置可拖 | 在 SAO 里拖动 HUD 图标后重启 | 位置保持（由 SAO 自己记住） |
| 4 | 打开/关闭面板 | **单击** SAO 的 HUD 图标；点面板外 | 面板打开；失焦自动关闭；再单击=重新打开 |
| 5 | 数据源=分类目录 | 向目录放/删文件 | 面板实时增减（≤1s） |
| 6 | 混排 lnk/exe/文件夹 | 三类混放 | 都显示（名称去扩展名、图标无小箭头）；其他类型不显示 |
| 7 | 点击启动 | 单击面板内 .lnk / .exe / 文件夹 | 启动程序 / 打开资源管理器；不进入子目录 |
| 8 | 拖拽重排+长按编辑+多选 | >4px 拖动；静止 400ms；多选拖动 | 重排（插入语义）/ 抖动多选 / 批量移动 |
| 9 | 顺序持久化 | 排序后重启 / 删掉某条目后重启 | 顺序与空格位置保持；被删条目记录保留不显示 |
| 10 | 失效快捷方式 | 删除某 .lnk 的目标后点击/查看 | 原生错误框；图标照常显示不灰显 |
| 11 | 面板可拉伸+记忆 | 拉伸后重启 | 尺寸保持（≥240×160） |
| 12 | 圆角 0–24 | 设置圆角 0 和 24 | 无黑角无锯齿 |
| 13 | 背景色+透明度 0–100 | 设透明度 0 | 只剩图标文字，背景全透明 |
| 14 | 弹出位置两种模式 | 设置切换 | 贴合鼠标落点 / 该屏居中 |
| 15 | 打开此文件夹入口 | 点面板右下角按钮 | 资源管理器打开分类目录 |
| 16 | 实时刷新 | 面板开着时向目录拖入文件 | 约 1s 内出现在面板 |
| 17 | 桌面其余区域不改动 | 桌面右键/框选/拖拽/Win+D | 行为与原桌面完全一致（我们不再往桌面写任何文件） |
| 18 | 分类操作菜单 | 托盘右键 → 某分类 | 打开面板/设置…/打开此文件夹/隐藏（删除启动器快捷方式）/重命名… |

其他验收点：

- **单击即打开**：SAO 的 HUD 图标支持单击触发动作（这就是换成 SAO 入口的直接收益，
  桌面 .lnk 的单击只选中，是 Windows 桌面的系统行为）。
- **Win+D 后 HUD 图标仍在**：HUD 是 SAO 的浮层，不属于桌面窗口。
  验收：按 Win+D → 桌面图标消失，HUD 图标仍在；点它面板照常弹出。
- **桌面图标不被程序乱动**：正常重启程序（不改任何设置），观察桌面图标位置
  与刷新次数 —— 不应出现"图标闪一下 / 位置被重排"。日志里也应有
  "快捷方式无变化，跳过重写"之类的记录。
- **改图标即时生效**：托盘→设置…→换一张图标图片 → 保存后桌面快捷方式图标在
  1–3 秒内更新（若系统图标缓存顽固，注销/重登一次或按 F5 刷新桌面）。
- **隐藏分类不被自动复活**：隐藏后重启程序，桌面不再出现该快捷方式，
  托盘菜单里该分类带"（已隐藏）"标记，仍可打开面板并"显示"。
- **单实例 + 唤醒**：程序已在跑时，再次双击桌面快捷方式 →
  **不弹任何对话框**，直接打开对应分类面板、面板出现在双击位置附近。
- **不进任务栏 / 不在 Alt+Tab**：任务栏和 Alt+Tab 里只有面板（打开时），
  没有任何"图标窗口"。
- **托盘菜单完整**：新建分类 / 每个分类的子菜单 / 打开数据目录 / 退出。

## 故障排查

- 日志：`%USERPROFILE%\DeskCountChen\.logs\app.log`。
- pythonw 下如果启动就崩，栈会写到 `%USERPROFILE%\DeskCountChen\.logs\crash.log`
  （`faulthandler` + `sys.excepthook`），不会静默消失。
- 环境变量 `DESKCOUNTCHEN_DEBUG=1` 开 DEBUG 级日志。
- 配置损坏时程序自动用默认配置且不覆盖原文件；`.order.json` 损坏时按名排序。
- 启动器 .lnk 丢失/异常：托盘→该分类→"显示（重建启动器快捷方式）"，或删掉
  `.icons\lnk_state.json` 后重启（会全量重建一遍）；也可点托盘
  「打开启动器目录（供 SAO 引用）」直接看文件在不在。
